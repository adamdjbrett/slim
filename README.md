# Slim Eleventy Port

Eleventy `3.1.5` port of the original Zola Slim theme.

## Credit

- Original theme: `jameshclrk/zola-slim`
- Upstream inspiration: `zhe/hugo-theme-slim`
- This repository is an Eleventy/Nunjucks port.

## Stack

- Eleventy `3.1.5`
- Nunjucks templates
- Luxon date filters
- Pagefind search indexing

## Global Data

- `_data/metadata.json`

## Commands

```bash
npm install
npm run start
npm run build
```

## Routes

- `/`
- `/blog/`
- `/tags/` and `/tags/:tag/`
- `/feed/feed.xml`
- `/sitemap.xml`
- `/robots.txt`
- `/humans.txt`
